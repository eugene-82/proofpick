# Task 018 — Frontend Core Flow

## Goal
Build the hackathon-ready user experience.

## Required Screens/States
1. Landing/search
2. Analysis progress
3. Result
4. Alternatives/comparison

## Result Must Show
- canonical product
- BUY / BUY_IF / SKIP / EARLY_ADOPTER
- evidence confidence
- repeated positive claims
- repeated negative claims
- source counts
- direct path to source links
- alternatives when applicable
- analysis age

## UX Rules
- Trustworthy, restrained language
- No sensational fake-review labels
- Real pipeline stages for loading
- Mobile usable
- Error states

## Do Not
- Add login
- Add notification/watch
- Build admin dashboard

## Done When
A first-time user can understand what the service does and complete a product analysis without explanation.
